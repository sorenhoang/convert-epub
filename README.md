# convert-epub

Turn text-based PDF books into reflowable EPUB files for your Kindle, right in the browser. The PDF never leaves your device: there is no server, and the page's Content Security Policy blocks connections to other sites.

It also includes an EPUB reader, so you can preview a converted book before sending it, or open any EPUB you already have.

## Features

- **PDF → EPUB 3.** Rebuilds paragraphs, removes running headers, footers and page numbers, rejoins words hyphenated at line ends, merges paragraphs split by page breaks, and splits chapters from the PDF bookmarks or from heading sizes.
- **Clear errors.** Password-protected, scanned (no text layer), undecodable and non-PDF files get a specific message instead of a broken EPUB.
- **Reader.** Paginated reading with a chapter list, page turns and arrow keys. The Preview button opens the converted book in the same reader.
- **Valid output.** Generated EPUBs pass [epubcheck](https://www.w3.org/publishing/epubcheck/) 5.3 with no errors in the test suite.

## Use it

1. Open the app and drop a PDF on the box, or click it to choose a file.
2. Wait for the page progress to finish, then click **Preview** to check the result or **Download** to save the `.epub`.
3. Send the file to your Kindle with [Send to Kindle](https://www.amazon.com/sendtokindle) (web, app, or email to your `@kindle.com` address). Amazon limits email attachments to 50 MB; the app warns you above that.

To read an EPUB you already have, open `/reader.html` and choose the file.

## Run locally

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev        # http://localhost:5173
```

Production build, served locally:

```bash
npm run build
npm run preview    # http://localhost:4173
```

`dist/` is a static site. Any static host works (GitHub Pages, Vercel, Netlify).

## Tests

```bash
npm test           # unit tests (Vitest)
npm run e2e        # browser tests (Playwright, builds and serves the app)
```

- EPUB validity tests run epubcheck, which needs **Java 11+** on your `PATH`.
- Browser tests need Chromium for Playwright. Install it once with `npx playwright install chromium`.
- Test PDFs are generated by the tests with pdf-lib. The only stored fixture is `test/fixtures/encrypted.pdf`.

## How it works

```
PDF ─ pdf.js ─▶ text items ─▶ layout ─▶ cleanup ─▶ structure ─▶ EPUB (jszip)
                (positions)   lines,    headers,    headings,
                              paragraphs page nums,  chapters,
                              columns    hyphens     metadata
```

The pipeline runs in a Web Worker so the page stays responsive.

| File | Role |
|---|---|
| `src/pdf.ts` | Loads the PDF with pdf.js: text items, metadata, outline |
| `src/layout.ts` | Groups text into lines and paragraphs; detects two-column pages |
| `src/cleanup.ts` | Removes running headers and page numbers; fixes hyphenation and page breaks; Unicode normalization |
| `src/structure.ts` | Detects headings and chapters; title and author fallbacks |
| `src/epub.ts` | Writes the EPUB 3 package |
| `src/errors.ts` | Error messages and checks for scanned or undecodable text |
| `src/convert.ts` | Runs the whole pipeline |
| `src/worker.ts`, `src/main.ts` | Web Worker and converter page |
| `src/reader-core.ts`, `src/reader.ts` | Reader (foliate-js) shared by the reader page and Preview |

## Limitations

- **Scanned PDFs are not converted.** There is no OCR yet.
- **Best on single-column prose.** Tables, figures and footnotes are not handled. Pages with more than two columns, and some table-of-contents pages, can be read in the wrong order.
- **Images are dropped.** Only text is carried over.
- **Language is always tagged as English.** This can affect Kindle hyphenation for other languages.
- **Heuristics are tuned on generated PDFs.** If a real book converts badly, open an issue with the symptom (split paragraphs, leftover headers, wrong chapters).
